## 1. 如何使用本节

这是整套路线图的权威资源参考。每条条目都已按其 2026–2027 年的实际可用状态核验。

>**配套路线图文档：**
> * **[The BlackHAT Roadmap（规范仓库）](https://github.com/SagarBiswas-MultiHAT/The-BlackHAT-roadmap)**：主课程体系、议题讨论与实时路线图更新。
> * **[主课程体系（阶段 -1 至 6）](../phases/PHASE_-1.md)**：从底层硬件到顶级行动的零基础到精英级攻防工程教学大纲。
> * **[BlackHat 长期生存战术](../black-bag/BlackHat_Long-Term_Survival_Tactics.md)**：权威的作战安全与数字身份手册。
> * **[理念：BlackHat 思维模式](Philosophy_The_BlackHat_Mindset.md)**：认知准则、对抗性假设挖掘与原始思维的心智模型。
> * **[工具清单](Tools_Inventory.md)**：按阶段编排的 300+ 工具综合目录，含安装与使用说明。
> * **[实验环境搭建指南](Lab_Setup_Guide.md)**：硬件规格、虚拟化拓扑与多层级 AD/EDR 实验环境配置。
> * **[MITRE ATT&CK 速查](MITRE_ATT&CK_Quick_Reference.md)**：覆盖所有对手战术与路线图阶段的专门战术映射。
> * **[常见问题](FAQ.md)**：作战与职业转型的综合问答。
> * **[结语](Final_Word.md)**：文档核验统计、研究者署名与前沿研究路线图。

> **推荐的精编路线图资源：**
> * **[Awesome Cybersecurity Paths](https://github.com/SagarBiswas-MultiHAT/awesome-cybersecurity-paths)**：为渗透测试人员、红队成员、蓝队成员与安全研究者精选的成长路径。
> * **[渗透测试路线图](https://github.com/SagarBiswas-MultiHAT/penetration-testing-roadmap)**：实战评估工作流、工具矩阵与项目执行方法论。
> * **[Awesome Cybersecurity Books](https://github.com/SagarBiswas-MultiHAT/awesome-cybersecurity-books)**：精选的攻防安全与底层系统文献。

使用本节的规则：

- **按阶段顺序学习。** 为阶段 0 列出的资源在阶段 4 帮不上你。不要跳着往前学。
- **深度优先于广度。** 读完一本书胜过开始十本。完成一个平台胜过浅尝五个。
- **在安装路线图中任何工具之前，「已废弃工具栈」一节（第 14 部分）是必读内容。** 教程会过时。工具会消亡。那一节能避免你在已死的基础上继续搭建。
- **博客与 YouTube 是补充，不是替代品。** 20 分钟的视频无法替代一本书所代表的 300 小时。用它们跟进技术更新与时事 —— 而不是当作主要学习途径。
- **所列价格为 2026–2027 年的大致数值。** 购买前请核实当前价格。

## 5. 必读书目 —— 按阶段排序

此处每本书都已在 2026 年核验。标注 *Classic* 的条目较老，但包含至今没有被任何现有替代方案取代的基础知识。价格与版次截至 2026 年。

> 如需覆盖各专业的攻防安全与底层工程文献大全，请参阅 [Awesome Cybersecurity Books](https://github.com/SagarBiswas-MultiHAT/awesome-cybersecurity-books)。

### 阶段 0：基础

| 书名 | 作者 | 年份 | 备注 |
|------|--------|------|-------|
| The C Programming Language | Kernighan and Ritchie | 1988（经典） | 先读这本。K&R 的 C 至今仍是最好的 C 入门书，无可替代。 |
| Operating Systems: Three Easy Pieces | Arpaci-Dusseau | 免费（ostep.org） | 并发、内存管理、持久化。可在线免费阅读。必读。 |
| The Linux Programming Interface | Kerrisk | 2010 | 深入的 Linux 内部机制：进程、信号、套接字、内存。阶段 0–2 的参考书。 |
| Computer Systems: A Programmer's Perspective | Bryant and O'Hallaron | 第 3 版 2015 | x86 汇编、存储层次、链接、栈。打通计算机科学理论与漏洞利用。 |
| The Linux Command Line | Shotts | 第 2 版 2019 | 可在 linuxcommand.org 免费获取。Shell 脚本、工具、文件系统。阶段 0 的日常参考。 |

### 阶段 1–2：Web 与网络安全

| 书名 | 作者 | 年份 | 备注 |
|------|--------|------|-------|
| The Web Application Hacker's Handbook | Stuttard and Pinto | 2011（经典） | 奠基性的方法论。技术至今仍然适用。PortSwigger Web Academy 覆盖了当下的新增内容。两本都要读。 |
| Hacking APIs | Corey Ball | 2022 | 现有最好的 API 安全测试书。内容新且实用。 |
| Bug Bounty Bootcamp | Vickie Li | 2021 | 聚焦 Web 的漏洞赏金方法论。阶段 1 的补充读物。 |
| Real-World Bug Hunting | Peter Yaworski | 2019 | 来自真实漏洞赏金项目的案例研究。适合与 Bug Bounty Bootcamp 配合阅读。 |
| Hacking: The Art of Exploitation (2nd ed) | Erickson | 2008（经典） | 把 shellcode 介绍给一代人。内存布局、栈溢出、格式化字符串讲解清晰。为打基础而读。 |

### 阶段 3：二进制漏洞利用与逆向工程

| 书名 | 作者 | 年份 | 备注 |
|------|--------|------|-------|
| Practical Binary Analysis | Andriesse | 2019 | ELF 内部结构、动态插桩、污点分析。作者提供免费 PDF。阶段 3 最好的起点。 |
| The Shellcoder's Handbook | Anley et al. | 2007（经典） | 栈溢出、堆溢出、格式化字符串。动手做阶段 3 之前先读它。 |
| A Guide to Kernel Exploitation | Perla and Oldani | 2010 | Linux 内核漏洞利用。内核 pwn 的标准参考。 |
| Attacking Network Protocols | Forshaw | 2017 | 协议逆向工程与模糊测试的圣经。阶段 3–4G 的交叉内容。 |
| The Fuzzing Book | Zeller et al. | 免费（fuzzingbook.org） | 模糊测试的理论与实现。阶段 4D 之前必读。 |
| The Car Hacker's Handbook | Craig Smith | 2016 | CAN 总线、汽车协议、OBD-II。提供免费 PDF。阶段 4G 汽车方向必修。 |

### 阶段 4：高级攻防

| 书名 | 作者 | 年份 | 备注 |
|------|--------|------|-------|

| Windows Internals Part 2 | Russinovich et al. | 第 7 版 2021 | 接续第 1 部分：存储、网络、高级内部机制。 |

### 阶段 5：GREATEST —— 漏洞研究与 0-Day 挖掘

| 书名 | 作者 | 年份 | 备注 |
|------|--------|------|-------|
| The Art of Software Security Assessment | Dowd, McDonald, Schuh | 2006（经典） | 迄今最权威的漏洞研究与代码审计指南。C/C++ 内存破坏、整数运算与设计缺陷发现。 |

| Surreptitious Software | Collberg and Nagra | 2009 | 混淆、水印、反调试与防篡改。理解并击破二进制保护必备。 |

| Windows Internals (7th ed, Parts 1 & 2) | Russinovich et al. | 2021-2022 | 系统架构、内存管理、内核对象与系统调用。Windows 内核漏洞利用原语的必备参考。 |

### 阶段 6：特种行动

| 书名 | 作者 | 年份 | 备注 |
|------|--------|------|-------|
| Practical Lock Picking | Deviant Ollam | 第 2 版 2012 | 标准的开锁教材。物理进入的基础。No Starch Press 出版。 |
| The Art of Intrusion | Kevin Mitnick | 2005（经典） | 真实的社会工程案例研究。原版，虽属历史但仍是 SE 方法论的基础。 |
| Influence: The Psychology of Persuasion | Robert Cialdini | 2021（修订版） | 说服的六大原则。理解社会工程为何有效的必读。 |
| Social Engineering: The Science of Human Hacking | Chris Hadnagy | 第 2 版 2018 | 来自 Social-Engineer.org 创始人的完整 SE 方法论。已更新现代技术。 |
| An Introduction to Mathematical Cryptography | Hoffstein, Pipher, Silverman | 第 2 版 2014 | 理解 PQC 所需的数学基础。深入讲解格密码。 |
| Post-Quantum Cryptography | Bernstein and Lange | 2009（Springer） | 学术界的 PQC 参考。可在线获取免费 PDF。配合 NIST FIPS 203/204/205 一起读。 |

> **已移除：** "The Art of Intrusion 2025" —— Kevin Mitnick 于 2023 年 7 月去世，并没有 2025 年版问世。原版《The Art of Intrusion》（2005）仍可作为历史读物。

### 2027 年最重要的攻击面

每个组织都在部署能访问邮件、文件、代码与基础设施的 AI 智能体。针对智能体系统的间接提示注入是当前影响力最大的新兴攻击面。其模式是：把恶意指令注入智能体会读取的外部数据（邮件、文档、网页、数据库结果）。智能体会把这些注入的指令当作来自用户的指令来执行。

这不需要底层模型存在任何漏洞。它只需要你能接触智能体将会读取的数据。

## 14. 已废弃工具栈 —— 请勿使用

此处列出的每款工具都已确认停更、无人维护，或检测率高到在已部署防御的环境中毫无实战价值。不要安装它们。不要盲从引用这些工具的教程 —— 先对照本清单。

> 📖 **完整清单参考：** 完整的 300+ 工具目录与现代活跃替代方案，见 [工具清单](Tools_Inventory.md#deprecated-stack)。

|-----------|------------|---------|
| CrackMapExec (CME) | NetExec (nxc) | 无活跃开发。NetExec 是仍在维护的直接分叉。语法几乎相同。 |
| Cuckoo Sandbox | CAPE Sandbox 或 Tria.ge | 已无人维护。Python 2 依赖链已损坏。CAPE 是仍在延续的社区分支。 |
| Evilginx2 | Evilginx3 | 旧版本含有已被商业产品收录的已知检测特征。同一仓库，更新的发布版本。 |
| MSOLSpray | CredMaster | 会被现代 Microsoft 检测捕获。CredMaster 用 FireProx（AWS API Gateway）大规模做 IP 轮换。 |
| LocalMonero | Haveno 或 Monero.com DEX | LocalMonero 于 2024 年 11 月永久关停。Haveno 是 P2P Monero 交易所的替代方案。 |
| gobuster（用于目录递归爆破） | feroxbuster | 不递归。feroxbuster 基于 Rust，默认递归，明显更快。 |
| dirb / dirbuster | ffuf 或 feroxbuster | 古老、缓慢、会产生噪声化的扫描特征。ffuf 快 10 倍且控制更细。 |
| Mimikatz（直接对在线系统投放） | nanodump + pypykatz | 会被每个 EDR 与 AV 产品捕获。用于实验环境学习与理解。绝不要直接对已部署防御的在线环境使用。用 nanodump 转储 LSASS，用 pypykatz 离线解析。 |

| BeEF | Evilginx3（用于凭据窃取） | 浏览器利用框架对现代浏览器已基本过时。基于 AiTM 代理的会话窃取更有效。 |

### Active Directory 实验环境配置

```powershell
# Windows Server 2022 -> 配置为域控制器
Install-WindowsFeature AD-Domain-Services
Install-ADDSForest -DomainName "lab.local" `
    -SafeModeAdministratorPassword (ConvertTo-SecureString "P@ssw0rd123!" -AsPlainText -Force)

# 重启后：把 Windows 11 工作站加入 lab.local 域

# 创建一个存在漏洞的 AD 环境用于练习：

# 可被 Kerberoast 的服务账户
New-ADUser -Name "svc_sql" -SamAccountName "svc_sql" -AccountPassword `
    (ConvertTo-SecureString "Password1" -AsPlainText -Force) -Enabled $true
Set-ADUser -Identity "svc_sql" -ServicePrincipalNames @{Add="MSSQLSvc/sql01.lab.local:1433"}

# 可被 AS-REP roast 的账户（无需预认证）
New-ADUser -Name "svc_backup" -SamAccountName "svc_backup" `
    -AccountPassword (ConvertTo-SecureString "Password1" -AsPlainText -Force) -Enabled $true
Set-ADAccountControl -Identity "svc_backup" -DoesNotRequirePreAuth $true

# ACL 配置错误：给低权限用户对某个组的 GenericWrite 权限
$user = Get-ADUser "lowpriv_user"
$group = Get-ADGroup "Domain Admins"
$acl = Get-Acl "AD:\$($group.DistinguishedName)"
$ace = New-Object System.DirectoryServices.ActiveDirectoryAccessRule `
    $user.SID, "GenericWrite", "Allow"
$acl.AddAccessRule($ace)
Set-Acl -AclObject $acl "AD:\$($group.DistinguishedName)"

# BloodHound CE 数据采集
.\SharpHound.exe -c All --zipfilename lab_bloodhound.zip
# 把 lab_bloodhound.zip 导入 BloodHound CE
# 运行：Shortest Paths to Domain Admins
# 运行：All Attack Paths from Domain Users
```

### 后量子密码（PQC）标准与工具

| 资源 | URL | 说明 |
|----------|-----|-----------|
| NIST FIPS 203 (ML-KEM / CRYSTALS-Kyber) | https://csrc.nist.gov | 后量子密钥封装标准。正在取代 RSA/ECDH 密钥交换。 |
| NIST FIPS 204 (ML-DSA / CRYSTALS-Dilithium) | https://csrc.nist.gov | 后量子数字签名标准。正在取代 RSA/ECDSA 签名。 |
| NIST FIPS 205 (SLH-DSA / SPHINCS+) | https://csrc.nist.gov | 基于哈希的后量子签名标准。保守的兜底方案。 |
| Open Quantum Safe (liboqs) | https://openquantumsafe.org | PQC 参考实现。构建并测试 ML-KEM 算法。 |
| NIST PQC Project | https://csrc.nist.gov/projects/post-quantum-cryptography | 跟踪所有 PQC 标准化进展的官方项目页。 |
| Cloudflare PQC Progress | https://blog.cloudflare.com | 真实世界的 PQC 部署跟踪。搜索 "post-quantum" 获取最新进展。 |
| Zeek Network Monitor | https://zeek.org | 网络安全监控器。用于 SNDL（先存储、后解密）流量检测。 |

> **SNDL 威胁现在就存在：** 国家级行为体今天就在收集加密流量，留待未来量子解密。任何用 RSA 或 ECDH 密钥交换加密的流量都可能被未来回溯解密。PQC 迁移不是未来的隐忧，而是当前的作战需求。
