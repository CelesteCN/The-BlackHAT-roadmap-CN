# 视觉资产与架构图

## 概述

本目录包含 **The BlackHAT Roadmap** 的视觉设计体系、赛博 HUD 横幅，以及 150 多张高分辨率架构图与执行流程图。

## 目录结构

- `banner.svg`：仓库主视觉横幅（赛博 HUD 风格）。
- `diagrams/`：按阶段划分的架构图、内存布局模型、网络拓扑、攻击杀伤链与决策树，覆盖阶段 -1 到阶段 6，以及各主配套卷。
